À propos

Un site statique de quelques fichiers, hébergé par GitHub Pages. Pas de serveur, pas de base de données, pas d'étape de compilation.

Modifier le site

Chaque page est un fichier HTML complet. Pour changer un texte, on ouvre le fichier, on édite, on enregistre — depuis GitHub dans un navigateur mobile, l'application GitHub, ou n'importe quel éditeur.

Pour ajouter une page : dupliquer un fichier existant, changer le titre et le contenu, puis ajouter le lien dans le bloc <nav> des quatre pages. Le lien de la page courante est mis en évidence automatiquement.

Publication

À chaque push sur la branche par défaut, GitHub Actions dépose le contenu du dépôt sur GitHub Pages. Une seule manipulation manuelle au départ : Settings › Pages › Source › GitHub Actions — le jeton des workflows n'a pas le droit de créer le site lui-même. Le fichier .nojekyll évite que Jekyll ne retraite les fichiers au passage.

Accessibilité et performance

  • Toutes les images ont un texte alternatif et des dimensions déclarées.
  • Les cibles tactiles font au moins 44 px de haut.
  • Le thème clair ou sombre suit le réglage du téléphone.
  • Le site entier pèse moins de 100 ko, images comprises.
